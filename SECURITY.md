# Security reporting

Report suspected vulnerabilities privately through this repository's **Security → Report a vulnerability** feature. Do not put credentials, recovery links, customer information or exploit details in a public issue.

Include affected routes, reproduction steps using accounts you control, expected versus observed behavior, and the impact. Do not test against another person's account, create real financial transactions, or run disruptive load tests.

Dependency checks run on pull requests, releases and weekly. A clean dependency scan is not a security certification. Authentication, privileged access, financial integrity and deployment changes require regression checks and review before release.
